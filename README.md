# 樹木の年間CO₂固定量計算

地上1.3 mで測定した樹木の胸高周囲長から，胸高直径と年間二酸化炭素固定量を計算する静的Webアプリです．1本分，10本分，および任意本数分の固定量を表示します．

## 計算式

胸高直径は，胸高周囲長をcmへ換算して次の式で求めます．

```text
D = C / π
```

- `C`：胸高周囲長 [cm]
- `D`：胸高直径 [cm]

年間二酸化炭素固定量は次の式で求めます．

```text
Y = 0.111 × {(X + 1.1)^2.6173 - X^2.6173}
```

- `X`：胸高直径 [cm]
- `Y`：年間二酸化炭素固定量 [kg/年]

内部計算では丸めず，画面表示時に原則として小数第3位へ丸めます．非常に大きい値や非常に小さい非ゼロ値は読みやすい科学表記に切り替えます．

## 使用方法

1. 胸高周囲長を入力し，`mm`，`cm`，`m`から単位を選びます．
2. 必要に応じて任意の本数（1〜10億本）を入力します．
3. 「計算する」を押します．
4. 胸高直径，1本分，10本分，任意本数分の年間CO₂固定量を確認します．

胸高周囲長はcm換算で6000 cm（60 m）以下のみ計算できます．入力値・現在の単位・任意本数・デフォルト単位はブラウザに保存されます．「入力をリセット」してもデフォルト単位の設定は保持されます．
